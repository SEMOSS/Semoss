# Example photograph

`earthrise.jpg` is a resized copy of the Apollo 8 Earthrise photograph by Bill Anders,
December 24, 1968. Image credit: NASA/Bill Anders.

- [Image and original credit](https://science.nasa.gov/resource/apollo-8s-iconic-earthrise/)
- [Downloaded JPEG](https://assets.science.nasa.gov/dynamicimage/assets/science/psd/solar/2023/09/a/as08-14-2383-1.jpg?crop=faces%2Cfocalpoint&fit=clip&h=3000&w=3000)
- [NASA media usage guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/)

The bundled image is photographic source material, not generated imagery. It was
resized to fit within 1600 x 1600 pixels and JPEG-encoded for a compact example.
The example includes its photo credit on the slides and source links in the notes.
The slide design is a SEMOSS example; NASA has not reviewed or endorsed it.

Use this image for relevant subject matter. For a different brief, substitute an
appropriate supplied image and its credit, or choose another example composition.
